<p align="justify">
Este proyecto aborda el análisis global e integral del fraude en transacciones de tarjetas de crédito y débito. Combina SQL Server para el procesamiento masivo de datos (ETL y consultas analíticas), Power BI para la inteligencia de negocio y visualización interactiva, y Python (Google Colab) para el modelado predictivo mediante Machine Learning.
</p>
El objetivo principal es responder a tres preguntas estratégicas del negocio:

1. **¿Cuáles son los patrones y brechas de seguridad en los métodos de pago y canales de venta?**
2. **¿Qué comportamiento presentan los verdaderos fraudes frente a los falsos positivos en montos elevados?**
3. **¿Podemos predecir transacciones fraudulentas con alta precisión a pesar del fuerte desbalanceo de clases?**
